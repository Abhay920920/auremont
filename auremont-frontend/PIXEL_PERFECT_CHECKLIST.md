# Pixel Perfect Review Checklist

Before finalizing any page, audit the following across ALL breakpoints (320px to 2560px):

- [ ] **Typography Rhythm**: Are headings properly scaled? Is body text legible (minimum 16px base)?
- [ ] **Whitespace**: Are sections separated by 128px or 160px on desktop? (64px to 80px on mobile)
- [ ] **Alignment**: Does the grid align perfectly on the left and right edges?
- [ ] **Contrast**: Is text legible against image backgrounds?
- [ ] **Interactions**: Do all buttons and links have hover AND focus states?
- [ ] **Performance**: Do animations drop frames? Avoid animating layout properties (width/height/margin), animate `transform` and `opacity` instead.
- [ ] **Accessibility**: Can you navigate the page fully with a keyboard?
