# UI Component Library

## Buttons
- **Primary**: Solid Champagne Gold background, Matte Black text. Uppercase, tight tracking.
- **Secondary**: Transparent background, 1px Stone Gray border, Ivory text. Hover to border Champagne Gold.
- **Text Button**: Underlined text, zero padding, smooth color transition on hover.

## Inputs
- **Base**: Transparent background, 1px border.
- **Focus**: Border turns Champagne Gold, slight inner glow.
- **Typography**: Sans-serif, 16px to prevent iOS auto-zoom.

## Cards
- Minimalist presentation. 
- Image container takes up 80% of the card.
- Text sits below with ample padding.
- No heavy drop shadows. We use subtle 1px borders and lift animations instead.
