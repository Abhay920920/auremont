# RARE NUTS — Integration Test Gap List & Database Boundary Analysis

**Purpose:** Documenting system behaviors that **CANNOT** be proven by unit mocks and explicitly require real database/network integration testing.

---

## 🗄️ Database & Concurrency Gaps (Requires PostgreSQL Container)

1. **Pessimistic Row Locking (`SELECT * FROM "products" ... FOR UPDATE`)**:
   - *Unit Limitation*: Jest unit tests mock `tx.$queryRaw`. They cannot test whether PostgreSQL actually locks product rows or prevents concurrent transaction updates.
   - *Integration Test Required*: Multi-threaded concurrent order placement against PostgreSQL.

2. **Prisma Transaction Rollback (`$transaction`)**:
   - *Unit Limitation*: Mock transactions execute in JS memory. They do not simulate SQL constraint rollbacks (e.g., unique index violations, foreign key deletions).
   - *Integration Test Required*: Trigger constraint errors during `Address` creation and assert PostgreSQL rolls back `Product` stock decrements.

3. **Database Unique Constraints (`@@unique`)**:
   - *Unit Limitation*: Unit tests mock `PrismaClientKnownRequestError`. Real database duplicate key behavior is not tested.
   - *Integration Test Required*: Insert duplicate `CartItem(cartId, productId)` records into PostgreSQL.

---

## 🌐 Payment & Network Boundary Gaps (Requires Sandbox / E2E Testing)

1. **Razorpay Webhook Signature Handshake**:
   - *Unit Limitation*: Unit tests mock HMAC signatures with static secret strings.
   - *Integration Test Required*: Send HTTP POST webhooks to `/payments/webhook` with headers generated by Razorpay Test Sandbox.

2. **PDF E-Invoice Layout Rendering**:
   - *Unit Limitation*: `OrderInvoiceModal.spec.ts` tests React data formatting, not actual canvas/PDF pixel rendering.
   - *Integration Test Required*: Playwright visual regression test of printed PDF invoice output.

3. **Vercel Serverless & Edge Runtime Behavior**:
   - *Unit Limitation*: Unit tests run under Node.js Jest.
   - *Integration Test Required*: Pre-deploy deployment test on Vercel preview environments.
